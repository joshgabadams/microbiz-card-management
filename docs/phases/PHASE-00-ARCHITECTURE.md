# Phase 00 — Architecture & Scope

## Objective
Freeze product structure before feature implementation.

## Deliverables
- Main navigation map
- Route map
- User journey map
- Security/UI constraints
- API capability map
- Status vocabulary placeholders
- Folder architecture

## Exit Criteria
- Every MVP capability has a route or explicit modal/drawer destination.
- No page is created without a defined operational purpose.
- API responsibilities are separated from presentation.
